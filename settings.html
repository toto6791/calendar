Синхронизация

Събитията се пазят във файл events.json в частно хранилище в GitHub. Въведете едни и същи данни на телефона и на компютъра, и двете устройства ще виждат едни и същи събития.

Как да подготвя GitHub (еднократно)
  1. В GitHub натиснете New repository. Име, напр. kalendar-data. Изберете Private и отметнете Add a README file. Натиснете Create repository.
  2. Отидете на Settings → Developer settings → Personal access tokens → Fine-grained tokens и натиснете Generate new token.
  3. Дайте име, изберете срок на валидност. При Repository access изберете Only select repositories и посочете хранилището от стъпка 1.
  4. При Permissions → Repository permissions намерете Contents и изберете Read and write.
  5. Натиснете Generate token и копирайте ключа (започва с github_pat_). GitHub го показва само веднъж.
  6. Попълнете формата по-долу на всяко устройство.

Ключът дава достъп само до това едно хранилище. Пази се само в браузъра на устройството. Не го записвайте във файловете на сайта и не го качвайте в GitHub.
